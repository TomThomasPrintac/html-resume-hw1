# My Resume - HTML Homework 1

A multi-page resume website built with plain HTML only (no CSS, no JavaScript).

## Pages

- `index.html` - main resume: general information, education, work experience, skills
- `hobbies.html` - list of my hobbies
- `contact.html` - contact details (phone, email)

```
.
├── index.html
├── hobbies.html
├── contact.html
└── images/
    └── profile.jpg
```
